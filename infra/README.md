# infra/

| Сервис | Профиль | Порт | Зачем |
|--------|---------|------|-------|
| Postgres 17 | базовый | 5433 | OLTP-база компании из сценария (сырые источники) |
| Redpanda (Kafka API) | `stream` | 19092 | стриминговый деплой (антифрод) |
| MLflow | — (локально, `make mlflow`) | 5000 | трекинг экспериментов, sqlite в `mlflow.db` |

Ресурсы ноутбука ограничены (6 GB VRAM, ~8 GB свободной RAM): сервисы поднимаем под этап и гасим после.
Новые сервисы добавляются сюда профилями + строка в таблицу.
