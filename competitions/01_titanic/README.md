## Главные мысли

1. **Задача почти решена правилом.** Пол — 0.787, пол + группа — 0.816, лучшая модель — 0.842. Вся борьба — за женщин
   3-го класса (50/50) и мужчин 1-го класса (37%): на них 60% ошибок.
2. **Связи между объектами** (попутчики по билету) — сильный сигнал, но **избыточный**: модели без него теряют всего
   0.1–0.7 п.п. accuracy, потому что достают ту же информацию из размера группы, класса и тарифа. Абляция обязательна.
3. **Сырые доли обманывают** (порт Шербур «спасал», потому что там садился 1-й класс) — конфаундинг.
4. **Шум больше разницы.** Наивный t-тест по фолдам «значимо» различает всё; с поправкой Надо–Бенжио значимо только
   лучшее улучшение к правилу. Это навык для любых A/B-тестов.
5. **Модели одинаковые.** Корреляция OOF-вероятностей 0.91–1.0 — ансамбль не помогает. Потолок на этих признаках ≈ 0.85
   (оценка «оракулом»), мы на 0.84.
6. **Ошибки — это истории**, которых нет в данных: осталась с мужем, искала ребёнка, билет сотрудника с тарифом 0.
