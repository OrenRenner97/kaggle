# Kaggle++

Соревнования Kaggle: глубокие ноутбуки + прод-решение в виде переносимых артефактов. Общаемся на русском.

## Как работаем

- Сейчас основную часть пишет Claude, пользователь учится; разбираем и обсуждаем каждый ноутбук. Постепенно
  пользователь подключается и пишет части сам — тогда его код не переписываем молча, замечания — в README.
- Соревнования по одному, по плану из `PROGRESS.md`.

## Ноутбуки (`competitions/NN_slug/`)

- Минимум: `01_eda`, `02_models`, `03_errors`; можно больше, если задача требует.
- В каждом: матчасть с формулами, много осмысленных графиков, статистическая честность (интервалы, повторная CV,
  поправка Надо–Бенжио, абляции), раздел **«Мысли»** в конце.
- **Выводы в тексте пишутся по фактическим результатам.** После выполнения сверить каждое утверждение с выводом
  ячеек и графиками; расхождения исправить.
- Исходник ноутбука пишется в jupytext percent (`.py` в scratchpad) → `jupytext --to ipynb --set-kernel kaggle-plus` →
  выполнить (`make nb N=...`). В репозитории — только `.ipynb` с выводами. Ядро: `kaggle-plus`.
- Данные: `../../data/kaggle/<slug>/`.

## Прод (`src/kagglib/<slug>/`)

- `features.py` — признаки с явным состоянием (`fit` → JSON) и контекстом (что известно на момент предсказания:
  защита от утечек в CV и в проде). Ноутбуки импортируют отсюда.
- `model.py` — обучение и экспорт пакета в `models/<slug>/`: модель в нескольких форматах (ONNX; нативная `.so`
  с C ABI, где возможно; C++/CUDA, когда оправдано), `manifest.json` (sha256), `golden.csv`.
- `predict.py` — `Predictor` с бэкендами; CLI в `src/kagglib/cli.py`.
- Тесты в `tests/<slug>/`: утечки в признаках, паритет бэкендов, эталон, подмена артефакта.
- Общее между соревнованиями → `src/kagglib/common/`.

## Документация

- `competitions/NN_slug/README.md` — ноутбуки, таблица результатов, прод-команды, главные мысли.
- `src/kagglib/<slug>/README.md` — состав пакета артефактов, ABI, как перенести на другую платформу.
- Строки в `competitions/README.md` и `PROGRESS.md`.

## Ограничения

- Данные, артефакты, сабмиты, токены — не в git. Kaggle-токен: `~/.kaggle/access_token`.
- Сабмит на Kaggle и публикация GitHub Release — только после подтверждения пользователя.
- Железо: RTX 3050 6 GB, 30 GB RAM (~22 занято), 12 ядер. Большие данные — polars/DuckDB.

## Команды

`uv sync --all-extras` · `uv run pytest` · `make download C=<slug>` · `make nb N=<путь к ipynb>` ·
`make submit C= F= M=` · `uv run kagglib <slug> train|predict`
