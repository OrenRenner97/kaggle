# Kaggle++

Берём соревнование Kaggle и проживаем его как настоящий ML-проект: выдуманная компания, заказчик, команда,
грязные источники, data engineering, feature store, исследование, модели, деплой и мониторинг.
На каждом этапе разбираем четыре стороны: **матчасть**, **ML**, **Python**, **аналитику/бизнес**.

```
брифинг ─► постановка ─► сырые источники ─► DE ─► исследование ─► feature store
                                                                       │
          ретро + сабмит ◄─ мониторинг ◄─ деплой ◄─ оценка для бизнеса ◄─ модели
```

Прогресс: **[PROGRESS.md](PROGRESS.md)** · Соревнования: **[competitions/](competitions/README.md)**

## Этапы соревнования

| # | Этап | Результат |
|---|------|-----------|
| 0 | **Брифинг** | `BRIEF.md`: компания, боль, заказчик, команда и роли, ограничения |
| 1 | **Постановка** | бизнес-метрика ↔ ML-метрика, бейзлайн без ML, критерии успеха |
| 2 | **Сырые источники** | данные Kaggle разложены по «системам компании» с реалистичной грязью |
| 3 | **Data engineering** | raw → staging → marts (DuckDB), проверки качества, data contracts |
| 4 | **Исследование** | EDA, статистические гипотезы, разбор распределений |
| 5 | **Feature store** | признаки с point-in-time корректностью, offline + online |
| 6 | **Моделирование** | CV-схема, бейзлайн, альтернативы с теорией, эксперименты в MLflow |
| 7 | **Оценка для бизнеса** | калибровка, порог через деньги, интерпретация, ревью с заказчиком |
| 8 | **Деплой** | в каждом соревновании свой паттерн (см. ниже) |
| 9 | **Мониторинг** | дрейф, деградация, ретрейн, имитация A/B |
| 10 | **Ретро + сабмит** | сабмит на Kaggle, выводы, переиспользуемое → `src/mlkit/` |

Этапы без сроков; по ходу заказчик может прислать «вводную» (сменились требования, сломалась выгрузка) — как в жизни.

## Паттерны деплоя (по одному на соревнование)

батч по расписанию · REST API (FastAPI + Docker) · встроенная модель (ONNX) · оркестрированный батч ·
онлайн-скоринг + shadow mode · стриминг (Redpanda/Kafka)

## Быстрый старт

```bash
uv sync --all-extras                 # окружение
uv tool install kaggle --with six    # Kaggle CLI; токен в ~/.kaggle/access_token
make download C=titanic              # данные → data/kaggle/titanic
make infra-up                        # Postgres для сырых источников
make mlflow                          # http://127.0.0.1:5000
uv run pytest
```
