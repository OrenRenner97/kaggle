# Kaggle++

Берём соревнование Kaggle и разбираем его до конца: **ноутбуки** с максимумом анализа, матчасти и графиков, и
**прод-решение** — модель в виде переносимого артефакта (ONNX, нативная библиотека с C ABI, дальше — C++/CUDA),
который встраивается в любую платформу.

```
соревнование ──► 01_eda ──► 02_models ──► 03_errors ──► kagglib/<slug> ──► артефакты
                 анализ     модели и CV    ошибки,       признаки,          ONNX · .so · формула
                 и мысли    с матчастью    SHAP          обучение, тесты    + эталон и manifest
```

Прогресс: **[PROGRESS.md](PROGRESS.md)** · Соревнования: **[competitions/](competitions/README.md)**

## Карта репозитория

| Папка | Что там |
|-------|---------|
| `competitions/NN_slug/` | ноутбуки и README с итогами и «мыслями» |
| `src/kagglib/<slug>/` | прод: признаки, честная CV, обучение, экспорт, инференс ([пример](src/kagglib/titanic/README.md)) |
| `src/kagglib/common/` | общее: пакет артефактов с хэшами, сборка и загрузка нативных моделей |
| `src/kagglib/cli.py` | `uv run kagglib <slug> train / predict` |
| `tests/<slug>/` | тесты признаков (утечки!) и паритета всех бэкендов |
| `models/`, `data/` | артефакты и данные — только локально; артефакты публикуются в GitHub Releases |

## Ноутбук — это

- матчасть рядом с кодом: формулы, почему именно эта модель;
- статистическая честность: интервалы, повторная CV, поправки на множественные и зависимые сравнения;
- графики, по которым видно вывод, а не просто «картинка для галочки»;
- раздел **«Мысли»**: неочевидные наблюдения, которые переносятся за пределы соревнования.

## Прод-решение — это

- признаки в `.py` — тот же код в ноутбуках, CV и инференсе;
- пакет артефактов: модель в нескольких форматах + `manifest.json` (порядок признаков, порог, sha256) + `golden.csv`
  для проверки реализации на другой платформе;
- тесты на паритет: все бэкенды дают одно и то же до 1e-6.

## Быстрый старт

```bash
uv sync --all-extras
uv tool install kaggle --with six            # токен: ~/.kaggle/access_token
make download C=titanic
uv run kagglib titanic train
uv run kagglib titanic predict --input data/kaggle/titanic/test.csv --output sub.csv --backend native
uv run pytest
uv run jupyter lab                           # ядро «Python (kaggle-plus)»
```
